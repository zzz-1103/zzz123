# 林黛玉网页版 · 后端部署教程（Netlify 版）

这套后端干三件事：
1. **代理 DeepSeek**——API key 藏在 Netlify 环境变量里，前端再也看不到
2. **存聊天记录**——每个人用昵称登录，说的话全部存进 Neon 数据库
3. **管理后台**——带密码，按人查聊天记录、导出 CSV

架构：

```
Netlify 前端站（黛玉.html）
        ↓
Netlify Functions 后端（/api/* + 后台函数 /bg/chat）
        ↓                        ↓
   Neon（PostgreSQL）      DeepSeek API
```

> **为什么最后选 Netlify**：Render 要绑卡（银联不行）、Hugging Face 的 Docker Space 要付费、
> Back4App 免费档只有 60 分钟、Zeabur 要自带 Kubernetes 集群。
> Netlify 是唯一"免费 + 不要卡 + 国内已验证能通 + 你已有账号"的路。

## 二、新建一个 Netlify 站点专门跑后端

⚠️ 注意：**不要动你现在那个前端站**，我们新建一个独立站点。

1. 打开 https://app.netlify.com → 点 **Add new site** → **Import an existing project**
2. 选 **Deploy with GitHub** → 授权 → 选仓库 **`zzz123`**
3. 分支选 **`main`**
4. 构建配置（如果 Netlify 自动填了，就对照检查）：
   - **Base directory**：`daiyu-backend`
   - **Build command**：留空
   - **Publish directory**：`public`
   - **Functions directory**：`netlify/functions`
5. 点 **Deploy**

> 仓库根目录已经放好了 `netlify.toml`，里面写好了上面这些配置，Netlify 一般会自动读取。

---

## 三、配置环境变量

站点页面 → **Site configuration** → **Environment variables** → **Add a variable**，逐个添加：

| Key | Value |
|---|---|
| `DATABASE_URL` | Neon 的 `postgresql://...` 连接串 |
| `DEEPSEEK_API_KEY` | `sk-...`（你的真实 key） |
| `ADMIN_PASSWORD` | 你自己设的管理密码 |
| `ALLOWED_ORIGIN` | `https://lindaiyu.netlify.app` |
| `APP_API_KEY`（可选） | 随便一串难猜的，防止别人蹭后端 |

加完后 → **Deploys** → **Trigger deploy** → **Deploy site**。

---

## 四、验证后端

1. 等部署状态变成 **Published**
2. 浏览器打开 `https://<你的后端站点>.netlify.app/api/health`
3. 看到 `{"ok":true}` 就成功了

> 数据库表**不用手动建**：函数第一次运行时会自动创建。`schema.sql` 只是备查。

## 五、改前端并部署到 Netlify

1. 打开 `D:\DaiyuApp\index.html`，找到顶部这行：

```js
const BACKEND = 'https://YOUR-BACKEND.onrender.com'; // TODO 改成你的后端网址
```

改成你的后端地址 `https://<你的后端站点>.netlify.app`。
（如果设了 `APP_API_KEY`，把下面 `APP_KEY` 填成一样的值）

2. 重新打包：

```powershell
cd D:\DaiyuApp
python pack.py
```

3. 把新生成的 `D:\DaiyuApp\黛玉.html` 拖到 https://app.netlify.com/drop 覆盖**前端站**部署。

## 六、查看聊天记录

1. 浏览器打开 `https://<你的后端站点>.netlify.app/admin`
2. 输入 `ADMIN_PASSWORD` 登录
3. 左边是聊过的人，点进去看完整聊天；右上角可**导出 CSV**

在 `D:\DaiyuApp\backend` 里**双击 `一键同步.bat`** → 推到 GitHub → Netlify 会自动重新部署。

## 八、关于回复延迟

因为绕开了 26 秒超时，聊天变成"先存后取"：

- 你发完消息 → 前端立刻显示你的话
- 黛玉的气泡先显示"黛玉正在想..."
- 每 2 秒问一次数据库，拿到回复就显示（闲聊约 4~6 秒，深思约 40~60 秒）

最多等 90 秒，超时会提示"黛玉一时没应声"。

## 常见问题

- **函数报错**：站点 → **Functions** → 点进函数看日志，多半是 `DATABASE_URL` 或 `DEEPSEEK_API_KEY` 没填对。
- **聊天失败（CORS）**：确认 `ALLOWED_ORIGIN` 里有 `https://lindaiyu.netlify.app`，且**结尾没有斜杠**。
- **想本地试**：需要用 `netlify-cli`（`npm i -g netlify-cli` 然后 `netlify dev`），一般直接部署测试更快。
- **安全提醒**：建议去 DeepSeek 后台设**消费上限**；管理后台密码设复杂点。
