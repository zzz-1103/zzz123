# 林黛玉网页版 · 后端部署教程

这套后端干三件事：
1. **代理 DeepSeek**——API key 藏在服务器环境变量里，前端再也看不到；
2. **存聊天记录**——每个人用昵称登录，说的话全部存进数据库；
3. **管理后台**——带密码，按人查聊天记录、导出 CSV。

架构：

```
Netlify（网页）  →  Back4App Containers（Node 后端 · Docker）  →  Neon（PostgreSQL）
                                     ↓
                                DeepSeek API
```

> **为什么用 Back4App**：
> - Render 要绑卡验证，Stripe 不支持国内银联卡 ❌
> - Hugging Face 的 Docker Space 现在需要付费 PRO ❌
> - Back4App Containers 免费档 **$0、明确写 no credit card required**，支持从 GitHub 构建自定义 Docker 容器 ✅

## 二、注册 Back4App

1. 打开 https://www.back4app.com → **Sign Up**（免费，**不需要银行卡**）
2. 用邮箱注册并完成验证

---

## 三、创建容器应用（Web Deployment）

1. 进入控制台，左侧找到 **Web Deployment**（容器部署）
2. 点 **Create new app** / **Deploy from GitHub**
3. 第一次会让你授权 Back4App 访问 GitHub → 选 **`zzz123`** 仓库 → 分支 **`main`**
4. 创建应用

> 仓库根目录已经放好了 `Dockerfile`（它会去 `daiyu-backend/` 子文件夹里构建我们的后端），Back4App 会自动识别。

---

## 四、配置环境变量

在应用的 **Settings → Environment Variables** 里，逐个添加：

| Key | Value |
|---|---|
| `DATABASE_URL` | Neon 的 `postgresql://...` 连接串 |
| `DEEPSEEK_API_KEY` | `sk-...`（你的真实 key） |
| `ADMIN_PASSWORD` | 你自己设的管理密码 |
| `ALLOWED_ORIGIN` | `https://lindaiyu.netlify.app` |
| `APP_API_KEY`（可选） | 随便一串难猜的，防止别人蹭后端 |

加完后点 **Deploy / Redeploy**，等构建完成（首次约 3~6 分钟）。

---

## 五、验证后端

1. 等应用状态变成 **Running**
2. 浏览器打开：`https://<你的应用地址>/api/health`
3. 看到 `{"ok":true}` 就成功了

> 数据库表**不用手动建**：后端启动时会自动创建。`schema.sql` 只是备查。

---

## 六、改前端并部署到 Netlify

1. 打开 `D:\DaiyuApp\index.html`，找到顶部这行：

```js
const BACKEND = 'https://YOUR-BACKEND.onrender.com'; // TODO 改成你的后端网址
```

改成 Back4App 给你的地址（形如 `https://xxx.b4a.run`）。如果后端设了 `APP_API_KEY`，把下面 `APP_KEY` 填成一样的值。

2. 重新打包：

```powershell
cd D:\DaiyuApp
python pack.py
```

3. 把新生成的 `D:\DaiyuApp\黛玉.html` 拖到 https://app.netlify.com/drop 覆盖部署。

---

## 七、查看聊天记录

1. 打开 `https://<你的应用地址>/admin`
2. 输入 `ADMIN_PASSWORD` 登录
3. 左边是聊过的人，点进去看完整聊天；右上角可**导出 CSV**

---

## 八、以后改代码怎么更新

在 `D:\DaiyuApp\backend` 里**双击 `一键同步.bat`** → 推到 GitHub → Back4App 会自动重新构建部署。

---

## 常见问题

- **应用起不来**：看 Back4App 的 **Logs**，多半是 `DATABASE_URL` 或 `DEEPSEEK_API_KEY` 没填对。
- **端口报错**：本后端会自动读取平台给的 `PORT` 环境变量，一般不用管。
- **聊天失败**：确认 `index.html` 的 `BACKEND` 是 Back4App 地址、`ALLOWED_ORIGIN` 里有 `https://lindaiyu.netlify.app`。
- **想本地先试**：把 `.env.example` 复制成 `.env` 并填好，然后 `npm install` + `npm start`。
- **安全提醒**：建议去 DeepSeek 后台设**消费上限**；管理后台密码设复杂点。
